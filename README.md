# SportsTeamsApp

SportsTeamsApp is a full-stack web app for managing sports data, built as part of my software development internship at CorNet Mostar. The application allows administrators to manage teams, countries, and sports through a clean, structured interface with full CRUD functionality, along with filtering and pagination support.

It consists of an ASP.NET Core Web API backend connected to a SQL Server database via Entity Framework Core, and an Angular admin panel on the frontend for managing all entities through an intuitive dashboard.

SportsTeamsApp was developed with a clear separation between backend and frontend, using RESTful API principles, Entity Framework Core migrations for database management, and a component-based Angular architecture for the UI.
